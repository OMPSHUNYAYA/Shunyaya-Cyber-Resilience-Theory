# SCRT Verification v2.18.0

Verification is separated into historical regression, generated finite-system falsification, adversarial phase verification, and current principal/independent implementations.

- `Regression/` preserves representative theorem implementations from the strict-refinement chain.
- `Generated/` performs exhaustive/generated falsification, assumption-sharpness checks, and adversarial assurance-hardening verification beyond hand-built examples.
- `Hardening_Phase/` contains the v2.10, v2.16, and v2.17 principal and independent implementations.

Use the repository-root `verify.py` so repository integrity and mathematical evidence are reported under separate labels.
