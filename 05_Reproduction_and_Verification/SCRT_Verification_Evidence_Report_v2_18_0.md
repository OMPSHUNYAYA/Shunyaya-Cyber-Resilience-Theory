# SCRT Verification Evidence Report v2.18.0

SCRT reports verification evidence in separate layers so repository integrity is never confused with mathematical proof.

## Layer 1 — Repository integrity

The root self-test checks required files, machine-readable records, cryptographic binding of the frozen computational and machine-readable theorem core, local README links, UTF-8/LF normalization, and repository hygiene.

These are **repository integrity checks**, not mathematical theorem checks.

Editable scientific presentation files are intentionally outside the cryptographic identity.
