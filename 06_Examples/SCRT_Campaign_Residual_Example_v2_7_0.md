# Campaign Residual Example

Two campaign states can have the same current `Delta_C` profile while using different hidden recovery resources.

Before future extension, their current campaign values agree.

Append a recovery action whose resource claim conflicts with only one of the hidden current realizations.

After extension, one campaign state remains unable to combine the recoveries while the other can.

Therefore current campaign value is not continuation-complete, and the residual class must preserve exactly those distinctions visible under future campaign extensions.
